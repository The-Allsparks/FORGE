# Documentation and portfolio learning path

Documentation is the last 10–20 minutes, not a homework mountain.

## Foundation

- Photo of today's robot change
- One TRACE story sentence
- Vocabulary box in the notebook

## Developing

- Evidence record ([template](../templates/evidence-record.md))
- Dashboard row update with a mentor
- Redaction: no names, passwords, or raw video in git

## Integration

- Event retrospective after clinic and league meets
- Judging narrative: problem, test, evidence, iteration — not a software tour of seven logos ([judging one-pager](../templates/judging-one-pager.md))

## Competition readiness

- Engineering notebook ready for inspection/judging
- Enablement decisions written as **status**, not as hopes

## Pairing

Documentation rotates. The builder of a mechanism should still sign the state diagram; the writer should still hold a wrench the next Meeting A.
