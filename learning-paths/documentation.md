# Documentation and portfolio learning path

Documentation is the last 5–10 minutes, not a homework mountain.

## Foundation

- Photo of today's robot change
- One TRACE story sentence
- Vocabulary box in the notebook

## Developing

- Evidence record ([template](../templates/evidence-record.md)) — fill at least Date, Question, Observation, Decision, Next test; check award tags (A/B/C/D) when they apply ([filled example](../templates/evidence-record-example.md))
- Dashboard row update with a mentor
- Redaction: no names, passwords, or raw video in git
- Know where information lives: [evidence model retention matrix](../docs/evidence-model.md)
- Decision record when comparing options ([template](../templates/decision-record.md))
- Math evidence when a number drives a choice ([template](../templates/math-evidence.md))

## Integration

- Event retrospective after clinic and league meets ([template](../templates/event-retrospective.md))
- Failure record after injected or real failures ([template](../templates/failure-record.md))
- TRACE → portfolio workflow when a graph materially helps ([workflow](../docs/trace-portfolio-workflow.md))
- Judging narrative: problem, test, evidence, iteration — not a software tour of seven logos ([judging one-pager](../templates/judging-one-pager.md))
- Review award tags and promote strongest evidence to portfolio candidates every 2–3 weeks ([portfolio-candidate](../templates/portfolio-candidate.md))
- Subsystem owners and Initial Interview practice ([student-ownership](../templates/student-ownership.md))

## Competition readiness

- Engineering notebook ready for inspection/judging
- Enablement decisions written as **status**, not as hopes
- Portfolio validated against A201 format rules ([validation checklist](../templates/portfolio-validation.md), [award traceability](../docs/award-and-portfolio-traceability.md))
- Initial Interview practice: up to 5-minute presentation + Q&A

## Pairing

Documentation rotates. The builder of a mechanism should still sign the state diagram; the writer should still hold a wrench the next Meeting A.
