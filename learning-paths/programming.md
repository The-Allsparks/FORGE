# Programming learning path

Programming supports a working robot. It is not a separate course.

## Foundation

- Driver Station OpMode select, INIT, start, stop
- TRACE events and one recorded signal
- Read a CSV row and say input vs event

## Developing

- Team teleop that drives the built chassis
- Pedro simple path after the drivebase exists
- Passive AMPER/MIMIC/BEACON hooks only when the session says so

## Integration

- One-camera ViDAR observation OpMode (no motors) per [TEACHING.md](https://github.com/The-Allsparks/ViDAR/blob/main/docs/TEACHING.md)
- Intent tree on paper / HELM validate — no execute
- ECHO desktop selector tests — no match audio

## Competition readiness

- Feature flags default off
- Conventional auto and teleop with optional systems disabled
- Explain-back: how to roll back in the pit

## Pairing

Programmers sit with builders during integration minutes. Drive team names the teleop bugs.
