# Electrical learning path

Electrical reliability is a season priority. AMPER observes power; it does not fix wiring.

## Foundation

- ESD-aware handling, connector seating, labeled batteries
- Control Hub / Expansion Hub power architecture as taught by mentors using FIRST/REV docs (do not invent pinouts in FORGE)
- XT30 / power connector strain relief

## Developing

- Motor and encoder wiring direction documented for MIMIC
- USB camera strain relief for ViDAR
- DS/RC cable discipline for BEACON conversations

## Integration

- Passive AMPER voltage (and later current) on a wheels-off robot ([hardware test card](https://github.com/The-Allsparks/AMPER/blob/main/docs/validation/hardware-test-card.md))
- Correlate sag with mechanism starts in TRACE/AMPER CSV

## Competition readiness

- Spare battery procedure, voltage at inspect, no mystery adapters
- AMPER stays **passive** in matches until the dashboard says otherwise

## Pairing

Electrical students own the first power-up checklist with a mentor. Programming students must still be able to point to the voltage line on a graph.
