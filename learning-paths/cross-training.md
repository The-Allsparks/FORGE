# Cross-training

Do not isolate students permanently by discipline.

## Standing rotation (default)

Over each two-week block, every student should spend at least one Meeting A construction block **off** their home specialty:

| Home role | Cross-train with |
| --------- | ---------------- |
| Mechanical | Electrical cable routing + AMPER battery labeling |
| Electrical | Programming TRACE event on the circuit they wired |
| Programming | Drive-team repetitions; they must feel loop lag |
| Drive | Notebook closeout + one MIMIC/AMPER graph |
| Documentation | Mechanism assembly for 30 minutes |

## Pairs

Prefer mixed pairs: builder + programmer on the same subsystem during the 25-minute integration block.

## Explain-backs are shared

If only the programmer can answer "what is stale?", the team failed the session even if the code compiled.

## After Kickoff

Re-assign pairs to BIOBUZZ subsystems so that no mechanism has a single owner who misses a meet.
