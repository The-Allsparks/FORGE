### When to record (prompt catalog)

Record if the team does any of these — skip if not applicable this session:

| Topic | Example question |
| ----- | ---------------- |
| Capstan circumference | How far does the elevator move per motor rotation? |
| Motor torque | Can this motor hold the load at full extension? |
| Elevator velocity / acceleration | How fast can we lift without tipping or browning out? |
| Counterbalance force | How much help does the spring/elastic give? |
| Belt length / return geometry | Does return-side routing keep belt circumference fixed? |
| Pulley bend radius | Will the belt track or fold at this diameter? |
| Belt stretch | How much did the elastomer stretch under load? |
| Current / power budget | Did AMPER show sag when we commanded this move? |
| Cycle time | How long from floor to scoring height and back? |
| Auto path / localization error | How far did Pedro end from the target? |
| Reliability comparison | Out of N tries, how many succeeded? |

Do not invent motor constants, belt moduli, or game-rule numbers in FORGE. If you use a datasheet, note it here and credit it in the portfolio if promoted.

TRACE records measurements; students do the reasoning. AMPER is the source for current/voltage observations — do not invent thresholds here.
