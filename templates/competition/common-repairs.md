# Common repair procedures

Train all four students on P0 repairs before G8. Time targets from practice.

## P0 — fix before next match

| Symptom | Likely cause | Steps | Target time |
| ------- | ------------ | ----- | ----------- |
| Mechanism jammed | Game piece / misalignment | DS stop → clear → reset state → test | ___ min |
| Wheel not driving | Coupler / shaft | Inspect shaft collar; replace if stripped | ___ min |
| Loose bumper | Fastener | Retighten; zip-tie temp if needed | ___ min |
| Auto fails start | Wrong pose / wrong auto selected | Verify start position; reselect auto | ___ min |

## P1 — fix if time in pit

| Symptom | Steps |
| ------- | ----- |
| Intermittent sensor | Reseat connector; check strain relief |
| Low battery sag | Swap battery; log |

## Escalate to mentor

- Smoke, smell, crushed battery
- Structural failure
- Any wiring short

**Fallback:** swap to starter-bot module per [modular-architecture.md](../../season/2026-2027-biobuzz/docs/modular-architecture.md).
