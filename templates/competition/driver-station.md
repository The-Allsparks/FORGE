# Driver station checklist

**Every match** · Owner: Driver 2

- [ ] Gamepad connected; correct profile
- [ ] DS app connected to robot
- [ ] TeleOp selected (unless auto running)
- [ ] Volume / ECHO status: OFF unless dashboard approved
- [ ] Stop button reachable
- [ ] Cables secured — no trip hazard
- [ ] Driver 1 confirms enable readiness verbally

**Communication cue:** "Clear" / "Stop" / "Stuck" — team-defined at G6.
