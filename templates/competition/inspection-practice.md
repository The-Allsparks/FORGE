# Inspection practice checklist (team)

**Before first event; spot-check at league meets** · Not official FIRST form.

Verify against published 2026–2027 inspection materials when live.

- [ ] Robot fits size constraint (**verify** official limit when published)
- [ ] Bumpers present and secure if required
- [ ] Battery secure; no exposed conductors
- [ ] Power switch accessible
- [ ] No sharp edges or pinch hazards
- [ ] Control system legal (Hub, phones, wiring)
- [ ] Autonomous delay / start behavior understood
- [ ] Team can present **whole robot** to inspector in one pass

Official shortcut (when live): [FIRST inspection checklist](https://ftc-resources.firstinspires.org/ftc/event/inspection-check)
