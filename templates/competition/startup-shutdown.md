# Robot startup / shutdown procedure

## Startup (shop or pit)

1. Robot on blocks or clear of people
2. Battery connected; power switch on
3. Wait for Hub boot
4. DS connect; verify teleop **before** enable
5. Check dashboard optional-system status
6. Short drive test without game pieces in path
7. Enable only when exclusion zone clear

## Shutdown

1. DS stop
2. Disable teleop
3. Power switch off
4. Disconnect battery if storing or transporting
5. Log issues on post-match or shop log

**Never** leave battery connected unattended in hot car.
