# Robot pre-match checklist

**Every match** · Target: <2 minutes · Owner: ___________

- [ ] Battery charged; voltage logged on [battery-log.md](battery-log.md)
- [ ] Mechanisms in legal starting configuration — [mechanism-start-position.md](mechanism-start-position.md)
- [ ] Bumper / frame inspect — nothing loose
- [ ] Autonomous selected on DS — [auto-alliance-sheet.md](auto-alliance-sheet.md)
- [ ] Known-good release tag on robot — [software-release.md](software-release.md)
- [ ] TRACE / optional systems match dashboard status
- [ ] Driver station ready — [driver-station.md](driver-station.md)
- [ ] Match strategy reviewed — [match-strategy.md](match-strategy.md)

**If any fail:** fix or rollback before queueing. Do not enable untested features to "try it."
