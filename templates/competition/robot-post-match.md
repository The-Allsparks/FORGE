# Robot post-match checklist

**Every match** · Owner: ___________

- [ ] DS stop; robot disabled
- [ ] Note damage, jams, or missed auto — one line in match log
- [ ] Battery removed if hot or below team threshold
- [ ] Loose fasteners / zip-ties checked
- [ ] Log issues as GitHub/notebook items if repeat failure
- [ ] Reset mechanisms for next match
- [ ] Charge battery; update [battery-log.md](battery-log.md)

**Critical repeat failure:** pit lead + mentor — scope rollback per [pit-and-inspection.md](../../season/2026-2027-biobuzz/pit-and-inspection.md).
