# Award strategy

Think is a **continuous engineering-process objective**, not a trophy we pick in August. Other judged awards are **focused bets** made after official criteria and regional context are known.

**Authoritative award text:** [award-and-portfolio-traceability.md](../../../docs/award-and-portfolio-traceability.md) from the BIOBUZZ Competition Manual **Pre-Season V0** (re-verify after Kickoff). This page does not invent rubric language.

**Strategic influence:** Pratt, *Why Most FTC Teams Fail (And How Not To)* — focused awards, Think as process, portfolio organized for judges (adapted; not endorsed). Official FIRST rules override the video, including page limits.

## Do not lock a season award target yet

FORGE#24 already tracks Kickoff re-verify of award tables. Until V1 (or the published Kickoff manual) is checked:

## Working hypothesis (not a team decision)

Based on current Allsparks strengths — not on 2025–2026 DECODE results we do not have:

| Track | Likely focus | Why this team | Alternative if evidence is stronger elsewhere |
| ----- | ------------ | ------------- | --------------------------------------------- |
| **Think** | Always | Engineering records, gates, TRACE, student explain-backs | None — process is required anyway |
| **MCI** | **Control** | Software stack (Pedro, MIMIC, TRACE, sensors, cameras) is a real team investment **if** it ships as control-with-feedback, not as unused libraries | **Innovate** if a unique legal mechanism is the stronger story; **Design** if maintainability and packaging are the stronger story |
| **TA** | **Connect** | Professional partnerships, mentors, sponsors, and Friendly Hobbies are already part of the team story | Reach or Sustain only if outreach/sustainability evidence outruns partnership evidence |

Inspire still requires Think + one MCI + one TA plus team attributes ([traceability](../../../docs/award-and-portfolio-traceability.md)). It is not a separate documentation project.

## Portfolio: rubric map **and** one story

Judges must find evidence quickly. Students must still tell **one** engineering story (problem → alternatives → test → change).

| Judge looking for | Where to put it (≤15 content pages, V0) |
| ----------------- | --------------------------------------- |
| Think A–D | Process, comparison, lesson, math pages — already tagged on evidence records |
| Control (if selected) | One page: hardware/software components, challenge each solves, how each works, feedback used |
| Design / Innovate (if selected) | Photos + decision records; do not duplicate the Think comparison page |
| Connect (if selected) | Skills plan, mentors, sponsors, Friendly Hobbies — **not** as Think filler (V0 moved those out of Think) |

Use [portfolio-validation.md](../../../templates/portfolio-validation.md) and [portfolio-candidate.md](../../../templates/portfolio-candidate.md). Add a **page index** on the cover or page 1 so a judge can find Control vs Think without hunting.

**Page limits:** V0 is **15 content pages**, **15 MB**, cover excluded. Do not substitute numbers from any video. Re-verify at Kickoff.

## Shop-time rule

Award extras that fail the [four tests](guiding-principle.md) — especially test 4, practice time — are deferred. A prettier portfolio does not outrank a robot that cannot cycle.
