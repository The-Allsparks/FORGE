# FORGE guiding principle

**Build the simplest robot that performs our highest-priority cycles reliably, can be repaired between matches, and leaves time for programming and driver practice.**

This is a decision test, not a slogan. Mentors facilitate; students apply it. Official FIRST rules override any advice that produced this principle.

**Strategic influence:** Brogan M. Pratt, *Why Most FTC Teams Fail (And How Not To)* — adapted for The Allsparks (FTC 36117). Pratt does not endorse FORGE. See [pratt-why-teams-fail.md](pratt-why-teams-fail.md) and [references.md](references.md).

## Four tests

A mechanism, software feature, outreach extra, or schedule change ships on the competition robot only if **all four** are true:

| # | Test | Question students must answer |
| - | ---- | ----------------------------- |
| 1 | **Top-ranked need** | Does this address a capability on the current ranked list, not a leftover ambition? |
| 2 | **Performs reliably** | Do we have measured results (not "it worked once") that meet the [acceptance method](acceptance-criteria.md)? |
| 3 | **Team-repairable** | Can students reset, clear, or swap this between matches with tools we actually pack? |
| 4 | **Protects practice time** | Does adding or keeping this steal time from [protected programming and driver practice](robot-releases.md#competition-runway)? |

If any test fails, the item is **deferred** or **rejected** and written on the not-yet / will-not list. It is not "also built."

## How students use it (about two minutes)

Write the proposal in one sentence. Check the four boxes. If the team disagrees, measure or cut — do not add a second robot "just in case."

After a documented decision, **disagree and commit** until new evidence reopens it ([decision-gates.md](decision-gates.md#disagree-and-commit)).

## What this is not

- Not a ban on ambitious ideas. Ambition lives on the staged [robot releases](robot-releases.md) and the software roadmap.
- Not a requirement to copy another team's simple robot.
- Not an official FIRST judging criterion. Think still needs a visible engineering process ([award-strategy.md](award-strategy.md)).
