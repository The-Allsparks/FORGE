# Lab HW001 — Drivetrain inspection

| Field | Value |
| ----- | ----- |
| Lab ID | HW001 |
| Kind | hardware |
| Projects | PEDRO (chassis), TRACE |
| Difficulty | Foundation |
| Duration | 35 minutes |

## Objective

Find mechanical defects before they become "software bugs."

## Prerequisites

P005 structure. Mentor for later power.

## Safety

Unpowered unless mentor is inspecting a powered Hub separately.

## Procedure

1. Wheel screws, structure square, wire pinch points.
2. Battery retention.
3. TRACE or paper event per defect found or "none found, method was X."

## Observable result

Signed checklist.

## Failure injection

Mentor plants a loose wheel screw if safe.

## Evidence

Checklist + photo.

## Explain-back

Would TRACE have told us this? (No — look with eyes first.)

## Rollback / disable

n/a

## Fallback if hardware missing

Inspect a mock chassis.
