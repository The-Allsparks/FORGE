# Lab I001 — TRACE session closeout

| Field | Value |
| ----- | ----- |
| Lab ID | I001 |
| Kind | integrated |
| Projects | TRACE |
| Difficulty | Foundation |
| Duration | fits in a 10-minute closeout |

## Objective

Leave every meeting with an ordered story, not a pile of files.

## Prerequisites

TRACE configured or paper events. [TRACE student path](https://github.com/The-Allsparks/TRACE/blob/main/docs/student-learning-path.md).

## Safety

No PII or secrets in exports.

## Procedure

1. Export or photograph today's events.
2. One student retells order.
3. Tick the TRACE dashboard row.
4. Fill the [evidence record](../../templates/evidence-record.md): at minimum Date, Question, Observation, Decision, Next test. Check award tags (A/B/C/D) if any apply. If time is short because the robot still needs a wrench, fill the four-line minimum — do not skip entirely.

## Observable result

A teammate who was not at the laptop can retell the run.

## Failure injection

Shuffle events; restore order.

## Evidence

Redacted export path.

## Explain-back

Measurement vs event.

## Rollback / disable

`TraceMode.OFF`.

## Fallback if hardware missing

Paper cards.
