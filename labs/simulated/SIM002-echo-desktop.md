# Lab SIM002 — ECHO desktop cues

| Field | Value |
| ----- | ----- |
| Lab ID | SIM002 |
| Kind | simulated |
| Projects | ECHO |
| Difficulty | Foundation |
| Duration | 35 minutes (Meeting B repair block) |

## Objective

Practice pan, silence, and mute with match audio off.

## Prerequisites

[phase1-desktop](https://github.com/The-Allsparks/ECHO/blob/main/examples/phase1-desktop.md), [hearing-safety.md](https://github.com/The-Allsparks/ECHO/blob/main/docs/hearing-safety.md).

## Safety

OS volume low. Stop if ears ring. Headphones optional.

## Procedure

1. Confirm desktop audio flag default off, then enable only for the drill if mentors agree.
2. Identify left vs right.
3. Demonstrate mute / `driverEnabled=false`.
4. List silence reasons.

## Observable result

Mute path + written silence reasons.

## Failure injection

Unknown input must not become center pan.

## Evidence

Decision record screenshot or notes.

## Explain-back

ECHO is not a vision system.

## Rollback / disable

Audio off; mute.

## Fallback if hardware missing

Paper left/right with eyes closed.
