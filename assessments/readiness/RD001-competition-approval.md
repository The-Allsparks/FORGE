# Readiness check — competition approval

| Field | Value |
| ----- | ----- |
| ID | RD001 |
| Type | readiness |
| Projects | any optional capability |
| Difficulty | Competition readiness |

## Prompt

For one dashboard capability, answer every gate.

## Student may use

Dashboard, evidence records, project README maturity table.

## Student must not

Treat CI green, "the repo exists," or a FORGE session completing as approval. Combined desktop tests are not Control Hub stack acceptance ([stack-acceptance.md](../../docs/stack-acceptance.md)).

## Evidence required

All of:

- Correct behavior
- Safe failure
- Loop impact acceptable
- Rollback demonstrated
- Student explain-back
- Demonstrated benefit
- Repeatability

## Rubric

| Level | Criteria |
| ----- | -------- |
| Not yet | Any gate missing |
| Approaching | Practice-only evidence only |
| Ready | Mentors may consider status `approved` |

## Enablement implication

Mentors still decide. This check is necessary, not sufficient.
