# Rubric — session explain-back

| Field | Value |
| ----- | ----- |
| ID | R001 |
| Type | rubric |
| Projects | any |
| Difficulty | Foundation |

## Prompt

Use the session's explain-back questions.

## Student may use

Robot, redacted log, notebook. Not another student's filled answers.

## Student must not

Read the project README aloud as a substitute for observation.

## Evidence required

Spoken answers plus the session's named evidence.

## Rubric

| Level | Criteria |
| ----- | -------- |
| Not yet | Cannot state the driving question or disable path |
| Approaching | Correct vocabulary; weak connection to today's robot |
| Ready | Answers from today's evidence; names rollback |

## Enablement implication

Passing does **not** approve competition use.
