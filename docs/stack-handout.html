TeamCode

In this APK · composition root

Does: this year’s OpModes, hardware names, and adapters.

Why: the robot program decides when motors move. Libraries must not take over.

SHIFT

In this APK · input layer

Does: map sticks to named intents.

Why: next robot is a JSON change, not a Java rewrite of stick axes.

PULSE + contracts

In this APK · sampling

Does: sample each encoder, IMU, or voltage once per loop.

Why: duplicate Hub reads stretch loop time. Contracts keep libraries independent.

TRACE

In this APK · observe only

Does: flight-record what the robot sensed, believed, decided, and commanded.

Why: Driver Station lines cannot explain a brownout or a missed score later.

AMPER

In this APK · observe only

Does: watch Hub voltage (optional current). Does not cut motors.

Why: “weak drive” is often a sagging pack or a loose XT30, not the mixer.

Pedro Pathing

In this APK · OpModes hidden

Does: own chassis localization and path follow. Teleop sticks stay with Drive.

Why: conventional auto must still work with every optional turned off.

MIMIC

Designed · not in settings.gradle

Does: mechanism snapshots, later limits and interlocks. Phase 0 does not actuate.

Why: intake, turret, and hood need states and units, not copy-paste PID.

ViDAR

Designed · not in this APK

Does: turn camera images into range and bearing in robot space.

Why: pixels are not positions. Stale tracks are not field truth.

BEACON

Designed · not a watchdog

Does: ask whether hubs, cameras, and loops still look fresh.

Why: a running loop is not a fresh driver command. Official FTC stop still wins.

HELM

Designed · stays OFF

Does: name goals, timeouts, and fallbacks from lower-layer snapshots.

Why: students explain the plan. HELM must not drive or bypass safety.

ECHO

Designed · disabled

Does: turn a few chosen facts into sound for the driver. Never motors.

Why: eyes stay on the field. Silence is valid. Mute must not stop the robot.

FORGE + shop tools

Laptop · not a Gradle dependency

Does: enablement plan, Hub deploy, and TRACE graphs.

Why: laptop code is not live until the Hub has the APK. Curriculum is not robot code.
