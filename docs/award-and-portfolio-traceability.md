# Award and portfolio traceability

Map FORGE activities to FTC judged-award criteria and PORTFOLIO format rules so evidence collection stays cheap and targeted.

**Authoritative source:** [BIOBUZZ Competition Manual Pre-Season V0](https://ftc-resources.firstinspires.org/ftc/game/manual) (31 Jul 2026), Section 6. Re-verify after Kickoff (12 Sep 2026) full manual release.

- [ ] **Kickoff re-verify:** A201 and Tables 6-2–6-9 checked against V1 manual.

## How to use this page

Print the "Think criteria" and "A201 format" tables. During closeout, tag the session's evidence record with the matching topic letter (A/B/C/D). Every two or three weeks, review tags and promote the strongest candidates into the portfolio shortlist. See [portfolio-candidate promotion](#portfolio-candidate-promotion) and the documentation learning path.

## PORTFOLIO format rules (A201)

These are hard requirements. If the submitted file fails any row, judges may not review the content.

| Rule | Requirement | Check |
| ---- | ----------- | ----- |
| Cover page | 1 cover page with team number (36117); optionally: team name, table of contents, sponsors, logo, motto, robot/team photo | ☐ |
| Content pages | No more than **15 pages** of content (cover page is not counted as content) | ☐ |
| Page size | US Letter (8.5″ × 11″) or A4 (210 × 297 mm) | ☐ |
| Digital file size | Less than **15 MB** | ☐ |
| Season eligibility | Only progress, challenges, and accomplishments since **1 January 2026**; previous seasons referenced for growth only | ☐ |
| Student privacy | First names and last initials only; no full names; student photos permitted | ☐ |
| Typography | Avoid fonts under 10 pt; ensure readable contrast (WebAIM-style check) | ☐ |
| Self-contained | Judges will **not** click links, open websites, play videos, or accept extra printed papers; put essential evidence directly on the pages | ☐ |
| AI / research credit | If AI or other research tools were used, include a footnote or endnote (example: "Portfolio created by Team 36117 and ChatGPT") | ☐ |
| Submission | Submit as instructed by the Event Director and by the stated deadline (A202); bring a pit copy | ☐ |

## Think Award (Table 6-3)

The Think Award recognizes a team for their excellent PORTFOLIO documenting the engineering journey. The PORTFOLIO is the primary reference — judges may also ask follow-up questions in the pit.

### Required 1

The PORTFOLIO must include at least **one** of the following engineering topics. FORGE should intentionally generate concise evidence for **all four** so the team has choices when assembling 15 pages.

| Topic | Official wording (V0) | Plain-language version | FORGE source | Template / artifact |
| ----- | ----- | ----- | ----- | ----- |
| **A** — Engineering process | Evidence of use of the engineering process | Show the steps you followed: question → idea → build → test → learn → change | Session closeout, TRACE retell, explain-backs | [Evidence record](../templates/evidence-record.md) |
| **B** — Lessons applied | Lessons learned and applied relating to the design of their ROBOT | Something broke or surprised you, and you changed the robot because of it | Event retrospectives, failure records, reliability tests | [Event retrospective](../templates/event-retrospective.md) |
| **C** — Comparing choices | Show how you looked at different ideas and explain why you chose one over the other | We tried two options. Here is why we picked one. | Kickoff MVP mapping, mechanism decisions, belt/elevator choices | Decision record (see [#17](https://github.com/The-Allsparks/FORGE/issues/17)) |
| **D** — Math choices | Show how you used math to make decisions about your ROBOT or programming design | A number helped us decide: travel, torque, speed, force, current, path error | Construction calculations, AMPER observations, auto path analysis | Math evidence (see [#19](https://github.com/The-Allsparks/FORGE/issues/19)) |

### Encouraged 2

Information in the PORTFOLIO should be **easy to read and easy to find**.

> In V0, Think no longer lists mentor/recruitment/goals as encouraged Think criteria — those belong to Connect, Reach, and Sustain.

## Other judged awards

Awards marked "PORTFOLIO required" need a submitted PORTFOLIO. Awards marked "PORTFOLIO not required" may still benefit from portfolio pages but are judged primarily through interviews and pit observations.

### Machine, Creativity, and Innovation (MCI)

| Award | PORTFOLIO required? | Required criteria (summary) | Encouraged criteria (summary) | FORGE evidence sources |
| ----- | ---- | ----- | ----- | ----- |
| **Innovate** | No | Engineering work showing how the design was developed; creative/unique design; stable and reliable | Explain how design risks were reduced | Decision records, failure records, TRACE figures showing reliability |
| **Control** | **Yes** | PORTFOLIO must include: (a) hardware/software control components, (b) challenges each solves, (c) how each works; uses external feedback to improve robot | Consistent during most matches; reliability shown or improvement plan; engineering-process lessons for control development | TRACE → portfolio workflow, MIMIC/Pedro/ViDAR descriptions, AMPER observations |
| **Design** | No | Robot is elegant, efficient, practical to maintain; entire design or design process considered | Stands out aesthetically/functionally; design choices well-considered; effective and consistent with game plan | Construction photos, mechanism geometry, pit rebuild evidence |

### Team Attributes (TA)

| Award | PORTFOLIO required? | Required criteria (summary) | FORGE evidence sources |
| ----- | ---- | ----- | ----- |
| **Connect** | No | Skill development plan with goals and steps taken | Skills matrix, cross-training rotation, mentor learning |
| **Reach** | No | Outreach objectives, strategy, FIRST community support; successful recruitment of new teams/coaches/mentors/volunteers | Outside FORGE scope — team must produce outreach evidence separately |
| **Sustain** | No | Sustainability plan (financial, season planning, and/or long-term); track progress toward plans | Season plan, calendar, readiness dashboard (partial) |

### Inspire (Table 6-2)

| Criteria | Requirement |
| -------- | ----------- |
| Required 1 | Team must submit a **PORTFOLIO** |
| Required 2 | Strong contender for at least one award in each of: MCI, TA, and **Think** |
| Required 3 | Positive and inclusive; each member contributes |
| Required 4 | Team can share experiences and knowledge to judges |

Inspire is the highest-level award. The Think PORTFOLIO, a strong MCI showing, and TA evidence are all prerequisites — Inspire is not a separate documentation exercise.

## Interview structure (V0)

The 2026–2027 season uses an **Initial Interview** (not "Structured Interview"):

- Prepared oral presentation: up to ~5 minutes, uninterrupted
- Q&A: remaining time led by judges
- Total: at least 10 minutes
- Minimum 2 student representatives (A204)
- Bring a PORTFOLIO copy; robot demo optional
- One adult silent observer permitted (A208); adults may not coach

Practice this in S018 and cadence Meeting B closeout using the [judging one-pager](../templates/judging-one-pager.md). See [#14](https://github.com/The-Allsparks/FORGE/issues/14) for interview practice and student ownership.

## DECODE → BIOBUZZ V0 wording changes

Record these so the team does not use outdated language in the PORTFOLIO or during practice.

| Topic | 2025–2026 (DECODE) | 2026–2027 (BIOBUZZ V0) |
| ----- | ------------------- | ---------------------- |
| Think C | "trade off analysis / cost benefit analysis" | "comparing choices: show how you looked at different ideas and explain why you chose one" |
| Think D | "mathematical analysis used to make design decisions" | "math choices: show how you used math to make decisions about your ROBOT or programming design" |
| Think Encouraged | Resources (mentors, recruitment, goals) and organization | **Only** readability/organization; mentor/recruitment/goals now under Connect/Reach/Sustain |
| Interview name | Structured Interview | **Initial Interview** (scheduled in-person, unscheduled in-person, or remote) |

If Kickoff V1 changes these, update this table and check all FORGE templates that reference award topics.

## Stack roles (use correctly in portfolio content)

| Project | Role | Do not describe as |
| ------- | ---- | ------------------ |
| TRACE | Structured telemetry, logs, evidence (including AdvantageScope-compatible export) | The control system |
| AMPER | Electrical state and available power envelope | A motor commander |
| MIMIC | Mechanism state, homing, limits, interlocks, completion, faults | A chassis driver |
| ViDAR | Vision and field-state information | The autonomous system |
| BEACON | Communication health monitoring | A comms commander |
| HELM | High-level intent and behavior coordination (no chassis authority; does not bypass MIMIC) | The thing that drives |
| ECHO | Audio driver assistance | Telemetry |
| Pedro Pathing | Chassis motion (owns autonomous driving) | An Allsparks library |

## Portfolio-candidate promotion

Every two or three weeks during Meeting B closeout (~10 minutes), review evidence records and pick the strongest items for a shortlist. See [#16](https://github.com/The-Allsparks/FORGE/issues/16).

Each candidate identifies: engineering story, student explanation, supporting image/diagram/calculation/TRACE graph, Think topic (A/B/C/D), other award criteria, readiness, missing evidence, fit in 15 pages.
